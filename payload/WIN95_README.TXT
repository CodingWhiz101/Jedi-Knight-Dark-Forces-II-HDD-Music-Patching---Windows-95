JEDI KNIGHT - WINDOWS 95 HDD INSTALL

1. Copy this complete directory to a short path such as D:\GAMES\DARKF2.
2. Run: SETJEDIREG.BAT D:\GAMES\DARKF2
3. Run VERIFY95.BAT, then DISC_TEST.EXE.
4. Start JK.EXE. The quiet PCM/CDDA shim is selected by default.

SELECT_DEBUG.BAT enables detailed pcmcd_debug.log diagnostics.
SELECT_QUIET.BAT or RESTORE_QUIET.BAT restores the production build.
COLLECT_LOGS.BAT gathers current diagnostics under PCMLOGS.

MUSIC_PCM intentionally contains no Track19.wav, Track20.wav, or Track21.wav.
Do not copy GOG's winmm.dll or Vorbis DLLs into this directory.
