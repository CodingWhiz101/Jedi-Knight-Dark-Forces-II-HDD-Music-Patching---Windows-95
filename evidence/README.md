# Accepted hardware evidence

`pcmcd_debug.log` is the final Windows 95 continuous-loop run. It records seamless initial completion, provisional repetition, two matching `PLAY` adoptions, clean explicit stops/close, and no backend errors, read failures, underruns, recoveries, or scheduling gaps.

`VALIDATION.TXT` is the accepted PE/export/import/ISA/WAV/hash validation report for the hardware-tested binaries and 22.05 kHz PCM set. The soundtrack itself is intentionally not retained in this repository.

See `docs/HARDWARE_ACCEPTANCE.md` for the concise interpretation and accepted binary hashes.
